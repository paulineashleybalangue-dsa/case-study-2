### Project Description
The Philippine Customs Data Analysis project is a Python-based data analysis program designed to process and analyze a large Philippine Customs dataset.
The project demonstrates the use of Pandas and NumPy for data processing and numerical analysis, together with Matplotlib for visualization.


The program processes the dataset in chunks, applies the required filtering rules, creates summary tables, identifies the top results, compares Python loops with NumPy vectorization, validates the generated results, and records an audit log.


### Program Features
- Process a large CSV dataset using chunks
- Validate required dataset columns
- Clean and prepare the data
- Apply the declared filtering rules
- Calculate dutiable values
- Create value bands
- Generate grouped summaries
- Generate a pivot table
- Identify the top 10 results
- Compare Python loops with NumPy vectorization
- Generate a bar plot
- Generate a heatmap
- Validate analysis results
- Generate a validation report
- Record an audit log
- Save analysis results as CSV files
- Demonstrate the analysis through a Jupyter Notebook

### Data Processing and Filtering Rules
The program reads the dataset in chunks to process the large file efficiently. The following rules are applied:
- Required columns are checked before processing.
- dutiablevaluephp is converted to a numeric value.
- Rows with missing tariff quantity are removed.
- Rows with non-positive dutiable values are removed.
- Missing country-of-origin values are assigned to Missing.
- Dutiable values are converted to millions of Philippine pesos for analysis.
- Transactions are classified into the required value bands.
- The submitted results are generated using the full dataset and the declared filtering rules.


### Analysis
The program generates several summary outputs.


#### Grouped Summary
The data is grouped according to the required country-of-origin and tariff-quantity fields and summarized using dutiable value.


#### Grouped Two-Category Summary

#### Pivot Table

#### Top 10 Analysis
